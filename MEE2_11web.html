14 モンテカルロ法¶

ここではモンテカルロ法について学びます。モンテカルロ法は乱数を用いて確率的に数値計算を行う方法の総称です。（解析的に解けない）積分計算、物理現象、金融現象、生物現象、統計的推測に至るまで、解析的な手法が及ばない諸現象に幅広く用いられており、計算機能力の向上とともにその有用性が確立されてきました。

【数理工学のポイント：なぜ高次元問題でモンテカルロ法を使うのか？】
第06回で学んだ台形法（誤差 $O(N^{-2})$）やシンプソン法（誤差 $O(N^{-4})$）などの格子点に基づく数値積分は、1次元では非常に高速に収束します。しかし、次元 $d$ が大きくなると必要な格子点数が $N^d$ と爆発的に増大します（次元の呪い）。
これに対し、モンテカルロ法の誤差収束は $O(N^{-1/2})$ と緩やかであるものの、収束速度が次元 $d$ に依存しないという大きな利点があり、統計力学の多体問題や金融工学の高次元積分などで威力を発揮します。

乱数のseed（種）の設定¶

コンピュータ内において乱数とはあくまで疑似乱数です。要するに乱数を計算する式に基づいて乱数を出力しているのです。その際、乱数を計算する式に初期値を決める必要があります。典型的な例は線形合同法と呼ばれる下記の式に従う疑似乱数発生方法です。

\begin{equation} x_{i+1}=ax_i+b \hspace{1cm}\pmod{m}, \hspace{1cm} 0\leq x_i <m \end{equation}

$a,b,m$は整数であり、$x_0$をユーザーが決めるとこの式に従い乱数が生成される仕組みです。もちろん、上手に$a,b,m$を設定することが重要であり、それにより疑似乱数の周期が決まります。上式の$x_0$のようにユーザー側で設定する必要がある初期値のことを乱数の種（seed）と言います。乱数を使う場合には必ずseedを設定することを忘れないで下さい。numpy.randomにおいてseedを設定するには下記のようにrandom.seed()メソッドを用います。引数にseedを設定します。seedとしてはintもしくはnumpy配列（intの値）が使えます。詳しくはnumpy.random.seedを参照してください。
モンテカルロ法では初期値を数多く取り繰り返し計算機実験を実行することになります。そこで、下記ではforループ共に乱数を使う典型的な例を載せてます。

14.2 中心極限定理¶

確率論の最も重要な定理の一つである「中心極限定理」を数値実験で視覚化してみましょう。中心極限定理の数学的な表現は次の通りです。

（実用的な）中心極限定理
$X_1, X_2, \dots, X_n$ を同一の確率分布（ただし，平均 $\mu$，分散 $\sigma^2$ が有限）に従う独立な確率変数とする．このとき，$X_1, X_2, \dots, X_n$ の標本平均 $$ S_n = \frac{1}{n}(X_1 + X_2 + \dots + X_n) $$ に対して，平均 $0$・分散 $1$ に標準化した確率変数 $$ Z_n = \frac{\sqrt{n}}{\sigma}(S_n - \mu) $$ を考える．このとき，$Z_n$ の確率分布 $f_n$ は $n \to \infty$ で標準正規分布 $\mathcal{N}(0, 1)$ に収束する： $$ \lim_{n \to \infty} f_n(x) = \frac{1}{\sqrt{2\pi}} \exp\left(-\frac{x^2}{2}\right) $$

この定理の意味は「元の確率分布がどのような形（一様分布や歪んだベータ分布など）であっても、独立な確率変数の標本平均を標準化したものは $n \to \infty$ の極限で標準正規分布に従う」ということです。

(1) 拡散則（原点からの距離と時間の平方根則）¶

上のグラフを見ると、1Dランダムウォークはステップ数 $t$ が大きくなるにつれて原点から離れていく傾向がありそうです。

各ステップで $+1$ または $-1$ に等確率で移動する場合、$t$ ステップ後の位置 $x(t)$ の平均は $\langle x(t) \rangle = 0$ ですが、分散（二乗平均距離）は $$ \langle x(t)^2 \rangle = t $$ となり、ステップ数 $t$ に比例します。また、$t$ が十分大きいとき $x(t)$ は中心極限定理により正規分布 $\mathcal{N}(0, t)$ に従うため、原点からの平均距離 $\langle R(t) \rangle = \langle |x(t)| \rangle$ は時間の平方根 $\sqrt{t}$ に比例します（拡散則）： $$ \langle R(t) \rangle = \langle |x(t)| \rangle \approx \sqrt{\frac{2}{\pi} t} \approx 0.7979\sqrt{t} $$ （※この性質は、連続極限における拡散方程式（熱伝導方程式） $\frac{\partial u}{\partial t} = D \frac{\partial^2 u}{\partial x^2}$ の解の広がり方と本質的に同じものです。）

本当にこの法則が成り立っているか、1000サンプルの平均をとって調べてみましょう。

(2) レヴィの逆正弦法則（Arcsine law）¶

次に、1Dランダムウォークを $T = 1000$ ステップ行ったとき、 「全時間の何割をプラス側（$x > 0$）で過ごしたか（滞在時間割合 $t_d \in [0, 1]$）」 の確率分布を調べてみましょう。

素朴な直感では「プラスとマイナスに半分ずつ行くので、$t_d = 0.5$ 付近が最も多くなる（山型の分布になる）」と予想しがちです。しかし実際には、一度どちらかの領域へ大きく踏み込むと原点へ戻るのに時間がかかるため、 $t_d \approx 0$（ずっとマイナス側）や $t_d \approx 1$（ずっとプラス側）に集中するU字型の分布 になります。

この直感に反する現象は確率論で 逆正弦法則（Arcsine law） と呼ばれ、極限の確率密度関数は次の式で表されます。 $$ p(x) = \frac{1}{\pi \sqrt{x(1 - x)}} \quad (0 < x < 1) $$

import matplotlib.pyplot as plt

sample = 100000
t_max = 1000

for i in range(sample):
    np.random.seed(i)
    x = [0, 0]
    count_pos = 0
    for t in range(t_max):
        if int(np.random.rand() * 2) == 0:
            x[1] = x[0] + 1
        else:
            x[1] = x[0] - 1
        if x[0] + x[1] > 0:
            count_pos += 1
        x[0] = x[1]
    dtime[i] = count_pos / t_max

# ヒストグラムと逆正弦法則の理論曲線を描画

p_arc = 1.0 / (np.pi * np.sqrt(x_arc * (1.0 - x_arc)))
plt.plot(x_arc, p_arc, "r-", lw=2, label=r"理論曲線 $\frac{1}{\pi\sqrt{x(1-x)}}$")

import pygame
import numpy as np

    BLACK = (0, 0, 0)

    pygame.init()

    x = 10  # 初期座標（中央）

    while not done:
        for event in pygame.event.get():
            if event.type == pygame.QUIT:

            if i == x:
                pygame.draw.ellipse(screen, RED, [39 + i * 20, 39, 20, 20])
