12 常微分方程式¶

常微分方程式は自然・社会現象の記述から様々なものの設計に至るまであらゆる分野で用いられており、数値計算の力が最も役立つ分野の一つでもあります。これは、繰り返し文を用いて逐次的に方程式の数値解を記述できるという数値計算の能力が絶大な力を発揮することに依るものです。　　 まず、最も基本的な2変数の1階常微分方程式を範囲$x \in [a, b]$、初期値$[t, x]=[0, X_{ini}]$の下で数値的に解くことを考えます（常微分方程式の初期値問題）。

\begin{align*} x(0)&=X_{ini}\\ \frac{dx}{dt}&=f(t, x) \end{align*}

「常微分方程式を解くという事」は関数形を求める事です。上の例で言えば、$x(t)$の関数形を決めれば良いわけです。そこで、初期値$[0, X_0]$から始め上の方程式に従いながら時間刻み$h(=\frac{b-a}{n}(nは分割数))$で少しずつ時間を進め、それに対応する$x(t+h)$の数値解を求めることを考えます。解析解$x(t)$と区別するために数値解を$X(t)$と表すことにします。

\begin{align*} X(0)&=X_{ini}\\ X(t+h)&=X(t)+h\Phi(t, X(t)) \end{align*}

さらにアルゴリズムとして見やすくするためにステップ数$i$を用いて以下のように書き直します。

\begin{align*} X_0&=X_{ini}\\ X_{i+1}&=X_i+h\Phi(t_i, X_i) \end{align*}

ここで$i$は（時間の）ステップ数を表し、$t_i=h \times i$、$X_i=X(t_i)$を表します。常微分方程式の数値的に解く場合はこの$\Phi(X_i, t_i)$の取り方が重要でありそれによって精度が変わってきます。
以下では常微分方程式の数値的な解法として最も基本的なオイラー法と最もよく使われるルンゲクッタ法を学びます。

12.1 オイラー法（1階常微分方程式）¶

オイラー法では$\Phi(t_i, X_i)$を決めるために、$x(t+h)$をテイラー展開し$h$が十分小さいので$h^2$以上の項を省略します。

\begin{align*} x(t+h) & = x(t)+\frac{dx}{dt}h+\frac{1}{2!}\frac{d^2x}{dt^2}h^2+\frac{1}{3!}\frac{d^3x}{dt^3}h^3+ \cdots\\ & \approx x(t)+\frac{dx}{dt}h\\ &= x(t)+hf(t, x) \end{align*}

ここで解析解$x(t+h)$を数値解$X_{i+1}$へ置き換えて前式と比較すると$\Phi(t_i, X_i)=f(t_i, X_i)$となることが分かります。つまり、オイラー法の形式は下記のとおりになります。

\begin{align*} X_0 & = X_{ini}\\ X_{i+1} &= X_i+h\Phi(t_i, X_i)\\ &= X_{i}+hf(t_i, X_i) \hspace{1cm} (i=0,1,2, \cdots, n-1)\\ \end{align*}

オイラー法のアルゴリズム¶

Input $t_0, x_0, a, b, n$
$h \leftarrow \displaystyle{\frac{b-a}{n}} \\$ For $ i=0,1,2, \cdots , n-1 \$ $\hspace{10mm} X \leftarrow X+hf(t, X) \\$ $\hspace{10mm} t \leftarrow t+h \$ $\hspace{10mm} Output X \$ end For

それではオイラー法で下記の常微分方程式を解いてみましょう。

\begin{align*} \frac{dx}{dt}=-4(t-1)x\\ \end{align*}

$t$の範囲は$t \in [0,1]$、初期条件を$[t_0, X_0]=[0, e^{-2}]$、分割数は$n=10$とします。

#(前進差分)オイラー法
import numpy as np
import matplotlib.pyplot as plt
from math import *

def euler(t0, x0, a, b, f, n):
    h=(b-a)/n
    #print(h)
    t=np.zeros(n+1)
    x=np.zeros(n+1)
    t[0]=t0
    x[0]=x0
    #print(t0)
    for i in range(0,n):
        t[i+1] = t[i] + h
        x[i+1] = x[i]+ h*f(t[i],x[i])
        
    return t, x
    
def func1(t, x):
    return (-4)*(t - 1) * x

12.2 4次のルンゲクッタ法（1階常微分方程式）¶

オイラー法は非常に単純なので微分方程式の数値解法を理解する最適な方法ですが、誤差がより少なくなる微分方程式の数値解法があります。ここでは、よく使われる微分方程式の数値解法として4次のルンゲクッタ法を紹介します。

\begin{align*} X_0 &=X_{ini}\\ X_{i+1}&=X_i+h\Phi(t_i, X_i) \hspace{3cm} (i=0,1,2, \cdots, n-1)\\ \Phi(t_i, X_i)&=\frac{1}{6}(k_1 + 2k_2 + 2k_3 + k_4)\\ ただし、\\ k_1 &= f(t_i, X_i)\\ k_2 &= f(t_i+\frac{h}{2}, X_i+\frac{h}{2}k_1)\\ k_3 &= f(t_i+\frac{h}{2}, X_i+\frac{h}{2}k_2)\\ k_4 &= f(t_i+h, X_i+hk_3)\\ \end{align*}

この公式が成り立つ理由はここでは説明しません。（実は4次のルンゲクッタ法はテイラー展開の4次までの近似と一致します。）

4次のルンゲクッタ法のアルゴリズム¶

Input $t_0, x_0, a, b, n$
$h \leftarrow \displaystyle{\frac{b-a}{n}}$
For $i=0,1,2,\cdots , n-1 \\$ $ \hspace{10mm} k_1 \leftarrow f(t, X) \$ $ \hspace{10mm} k_2 \leftarrow f(t+\frac{h}{2}, X+\frac{h}{2}k_1) \\$ $ \hspace{10mm}k_3 \leftarrow f(t+\frac{h}{2}, X+\frac{h}{2}k_2) \$ $ \hspace{10mm}k_4 \leftarrow f(t+h, X+hk_3) \\$ $ \hspace{10mm}X \leftarrow X+\frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4) \$ $ \hspace{10mm}Output X \$ end For

先ほどと同じ常微分方程式を今度はルンゲクッタ法で数値的に解いてみます。

\begin{align*} \frac{dx}{dt}=-4(t-1)x\\ \end{align*}

$t$の範囲は$t \in [0,1]$、初期条件を$[t_0, X_0]=[0, e^{-2}]$、分割数は$n=10$とします。

# 4次のルンゲ＝クッタ法（1階常微分方程式）
import numpy as np
import matplotlib.pyplot as plt

def rungekutta(t0, x0, a, b, f, n):
    h = (b - a) / n
    t = np.zeros(n + 1)
    x = np.zeros(n + 1)
    t[0] = t0
    x[0] = x0
    
    for i in range(n):
        k1 = f(t[i], x[i])
        k2 = f(t[i] + h / 2.0, x[i] + h / 2.0 * k1)
        k3 = f(t[i] + h / 2.0, x[i] + h / 2.0 * k2)
        k4 = f(t[i] + h, x[i] + h * k3)
        x[i+1] = x[i] + (h / 6.0) * (k1 + 2.0 * k2 + 2.0 * k3 + k4)
        t[i+1] = t[i] + h
        
    return t, x

def func1(t, x):
    return -4.0 * (t - 1.0) * x

if __name__ == '__main__':
    t0 = 0.0
    x0 = np.exp(-2.0)
    a = 0.0
    b = 1.0
    n = 10

    t, x_rk = rungekutta(t0, x0, a, b, func1, n)
    
    plt.figure(figsize=(7, 5))
    plt.plot(t, x_rk, marker="v", linestyle="", color="green", label="4th Runge-Kutta $n=10$")
    plt.xlabel('$t$')
    plt.ylabel('$x(t)$')
    plt.title('4th-order Runge-Kutta Method ($n=10$)')
    plt.legend(loc='upper left')
    plt.grid(True)
    plt.show()

12.4 オイラー法（2階常微分方程式）¶

続いて、高階常微分方程式をオイラー法で解いてみます。既に微分方程式で学んだように高階常微分方程式は連立1階常微分方程式へ帰着できます。簡単のためここでは2階常微分方程式について考えます。

\begin{align*} \displaystyle{\frac{d^2x}{dt^2}=f(t, x, \frac{dx}{dt})} \end{align*}

ここで$\displaystyle{\frac{dx}{dt}=y}$とおくと \begin{align*} \frac{dx}{dt}&=y\\ \frac{dy}{dt}&=f(t, x, y) \end{align*} となる。一般的に表すと \begin{align*} \frac{dx}{dt}&=f_1(t, x, y)\\ \frac{dy}{dt}&=f_2(t, x, y) \end{align*} となるので、この連立1階常微分方程式にオイラー法を適用してみましょう。

\begin{align*} x(t+h)&= x(t)+hf_1(t, x, y)\\ y(t+h)&= y(t)+hf_2(t, x, y) \end{align*}

ステップ数を用いて表現すると

\begin{align*} X_0 &= X_{ini}\\ Y_0 &= Y_{ini}\\ X_{i+1} &= X_i+h\Phi_1(t_i, X_i, Y_i)\\ &= X_i + hf_1(t, X_i, Y_i)\\ Y_{i+1} &= Y_i+h\Phi_2(t_i, X_i, Y_i)\\ &= Y_i + hf_2(t, X_i, Y_i) \hspace{3cm} (i=0,1,2, \cdots, n-1)\\ \end{align*}

オイラー法(2階常微分方程式)のアルゴリズム¶

Input $t_0, x_0, y_0, a, b, n$
$h \leftarrow \displaystyle{\frac{b-a}{n}}\\$ For $i=0,1,2,\cdots , n-1 \$ $\hspace{10mm} X \leftarrow X+hf_1(t, X, Y) \\$ $\hspace{10mm} Y \leftarrow Y+hf_2(t, X, Y) \$ $\hspace{10mm} t \leftarrow t+h \\$ $\hspace{10mm} Output X, Y \$ end For

以下の常微分方程式をオイラー法で解いてみます。

\begin{align*} \frac{d^2x}{dt^2}=-x\\ \end{align*}

$t$の範囲は$t \in [0,10]$、初期条件を$[t_0, X_0, Y_0]=[0, 1, 0]$、分割数は$n=100$とします。
連立1階常微分方程式へ帰着させると

\begin{align*} \frac{dx}{dt}&= y(=f_1(t, x, y))\\ \frac{dy}{dt}&= -x(=f_2(t, x, y)) \end{align*}

ステップ数を用いて表現すると

\begin{align*} X_0&= 1\\ Y_0&= 0\\ X_{i+1} &= X_i + hY_i\\ Y_{i+1} &= Y_i + h \times (-X_i) \hspace{3cm} (i=0,1,2, \cdots, n-1)\\ \end{align*}

import matplotlib.pyplot as plt

def euler2(t0, x0, y0, a, b, f1, f2, n):
    h=(b-a)/n
    #print(h)

    y=np.zeros(n+1)

【考察】なぜオイラー法では振動の振幅が増大してしまうのか？¶

上記のシミュレーション結果を見ると、本来一定の振幅（$\pm 1$）で単振動を繰り返すはずの解が、時間とともに振幅が急激に増大していることが分かります。

質点力学で学んだように、方程式 $\frac{d^2x}{dt^2} = -x$ はバネについた質点の自由振動（調和振動子）を表しており、力学的エネルギー（ハミルトニアン）は $$E(t) = \frac{1}{2}x(t)^2 + \frac{1}{2}y(t)^2 = \text{一定}$$ として厳密に保存され、相図（$x$-$y$ 平面）上では半径 1 の真円を描き続けるはずです。

しかし、前進オイラー法の更新式から 1 ステップ後の振幅（エネルギーノルム）を計算すると、 $$X_{i+1}^2 + Y_{i+1}^2 = (X_i + hY_i)^2 + (Y_i - hX_i)^2 = (1 + h^2)(X_i^2 + Y_i^2)$$ となり、毎ステップ $(1 + h^2) > 1$ 倍ずつ人工的にエネルギーが増大してしまいます。 このように、オイラー法は長時間の物理シミュレーションでは法則を破綻させるため、より高精度なルンゲ＝クッタ法が必要となります。

上記と同様に今度は4次のルンゲクッタ法を用いて2階常微分方程式を解くことを考えてみましょう。
ステップ数を用いた表現は下記のとおりになります。

\begin{align*} X_0 &= X_{ini}\\ Y_0 &=Y_{ini}\\ X_{i+1} &= X_i+h\Phi_1(t_i, X_i) \\ Y_{i+1} &= Y_i+h\Phi_2(t_i, X_i) \hspace{3cm} (i=0,1,2, \cdots, n-1)\\ \Phi_1(t_i, X_i) &= \frac{1}{6}(k_1 + 2k_2 + 2k_3 + k_4)\\ \Phi_2(t_i, X_i) &= \frac{1}{6}(l_1 + 2l_2 + 2l_3 + l_4)\\ ただし、\\ k_1 &= f_1(t_i, X_i, Y_i)\\ l_1 &= f_2(t_i, X_i, Y_i)\\ k_2 &= f_1(t_i+\frac{h}{2}, X_i+\frac{h}{2}k_1, Y_i+\frac{h}{2}l_1)\\ l_2 &= f_2(t_i+\frac{h}{2}, X_i+\frac{h}{2}k_1, Y_i+\frac{h}{2}l_1)\\ k_3 &= f_1(t_i+\frac{h}{2}, X_i+\frac{h}{2}k_2, Y_i+\frac{h}{2}l_2)\\ l_3 &= f_2(t_i+\frac{h}{2}, X_i+\frac{h}{2}k_2, Y_i+\frac{h}{2}l_2)\\ k_4 &= f_1(t_i+h, X_i+hk_3, Y_i+hl_3)\\ l_4 &= f_2(t_i+h, X_i+hk_3, Y_i+hl_3)\\ \end{align*}

演習 12.4（2元連立4次ルンゲ＝クッタ法の実装）¶

調和振動子などの2階常微分方程式を解くための、2元連立4次ルンゲ＝クッタ法の関数 rungekutta2(t0, x0, y0, a, b, f1, f2, n) を完成させなさい。

※特に $k_4, l_4$ の計算時、第3引数に $y$ 方向の増分（$h \times l_3$）を正しく渡す点に注意しなさい。

# 演習 12.4：2元連立4次ルンゲ＝クッタ法（ひな形）
import numpy as np
import matplotlib.pyplot as plt

def rungekutta2(t0, x0, y0, a, b, f1, f2, n):
    h = (b - a) / n
    t = np.zeros(n + 1)
    x = np.zeros(n + 1)
    y = np.zeros(n + 1)
    
    t[0] = t0
    x[0] = x0
    y[0] = y0
    
    for i in range(n):
        k1 = f1(t[i], x[i], y[i])
        l1 = f2(t[i], x[i], y[i])
        
        k2 = f1(t[i] + h / 2.0, x[i] + h / 2.0 * k1, y[i] + h / 2.0 * l1)
        l2 = f2(t[i] + h / 2.0, x[i] + h / 2.0 * k1, y[i] + h / 2.0 * l1)
        
        k3 = f1(t[i] + h / 2.0, x[i] + h / 2.0 * k2, y[i] + h / 2.0 * l2)
        l3 = f2(t[i] + h / 2.0, x[i] + h / 2.0 * k2, y[i] + h / 2.0 * l2)
        
        # 【穴埋め】k4 と l4 を計算しなさい（yの増分は h * l3）
        k4 = # ここを記述
        l4 = # ここを記述
        
        # 次のステップを更新
        x[i+1] = x[i] + (h / 6.0) * (k1 + 2.0 * k2 + 2.0 * k3 + k4)
        y[i+1] = y[i] + (h / 6.0) * (l1 + 2.0 * l2 + 2.0 * l3 + l4)
        t[i+1] = t[i] + h
        
    return t, x, y

    return y
